# CPU Documentation

This folder contains the internal design explanation and architectural details of the 32-bit Single-Cycle RISC-V CPU.

The purpose of this documentation is not only to explain the Verilog modules, but also to describe how instructions move through the datapath, how control signals are generated, and how different hardware blocks interact during execution.

The processor was designed from scratch in Verilog HDL with the goal of understanding processor internals at the hardware level rather than simply simulating instruction behavior.

---

### memory_organization.md

Contains testing methodology, simulation observations, and waveform verification details.

## Design Philosophy

The processor follows a clean and modular single-cycle architecture where each hardware block is implemented separately and later integrated into the complete datapath.

Special focus was given to:
- datapath understanding
- instruction execution flow
- control logic generation
- branch handling
- memory interfacing
- simulation-based debugging

The project was tested using custom testbenches and waveform analysis in Vivado.
