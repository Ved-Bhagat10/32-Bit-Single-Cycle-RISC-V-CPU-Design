# 32-bit Single-Cycle RISC-V CPU (RV32I)

A 32-bit Single-Cycle RISC-V CPU designed and implemented in Verilog HDL based on the RV32I base integer instruction set architecture.

This project was built to understand how instructions are actually executed at the hardware level by designing the datapath, control logic, ALU operations, memory access logic, branching mechanism, and write-back flow from scratch.

The processor follows a single-cycle datapath architecture where instruction fetch, decode, execution, memory access, and write-back are completed within a single clock cycle.

---

## Features

- 32-bit RV32I-based processor
- Single-cycle datapath architecture
- Separate instruction and data memory
- 32 General Purpose Registers (GPRs)
- Register x0 hardwired to zero
- Arithmetic and logical instruction support
- Immediate instruction support
- Load and store operations
- Conditional branching support
- Jump and link instructions (`jal`, `jalr`)
- Immediate generator for I/S/B/U/J instruction formats
- ALU control unit for instruction decoding
- PC update logic for sequential and control-flow execution
- Word-addressable instruction and data memory

## Architecture Overview

The processor is divided into the following major hardware blocks:

- Program Counter (PC)
- Instruction Memory
- Control Unit
- Register File
- Immediate Generator
- Arithmetic Logic Unit (ALU)
- ALU Control Unit
- Data Memory
- Write-Back Multiplexer
- Branch and Jump Logic

The control unit generates the required control signals based on the instruction opcode, while the ALU Control Unit determines the exact ALU operation using `opcode`, `func3`, and `func7`.

Branch and jump instructions modify the Program Counter using dedicated PC update logic.

---

## Memory Organization

### Instruction Memory
- 256 × 32-bit words
- Total size: 1 KB

### Data Memory
- 256 × 32-bit words
- Total size: 1 KB

Both memories are word-addressable internally. Byte addresses generated by the ALU are converted into word indices using address alignment logic.

---

## Datapath Flow

For every instruction, the processor performs:

1. Instruction Fetch  
2. Instruction Decode  
3. Register Read  
4. Immediate Generation  
5. ALU Execution  
6. Memory Access (if required)  
7. Write Back to Register File  

All operations are completed in a single clock cycle.

## Simulation and Testing

The processor was verified using a Verilog testbench in Vivado.

The test programs included:
- Arithmetic operations
- Logical operations
- Shift operations
- Signed and unsigned comparisons
- Load/store operations
- Conditional branches
- Jump instructions
- Register write-back verification
- Memory access verification

Waveform analysis was used to verify:
- Control signal generation
- ALU operation selection
- Register file updates
- Memory reads/writes
- Branch target computation
- PC update behavior
